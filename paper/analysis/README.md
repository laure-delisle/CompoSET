# Paper analyses

Scripts behind the dataset-property and model-diagnostic analyses in the CompoSET paper.
Only code is versioned here. Every CSV, figure, and cache is regenerated by the scripts and ignored by git.

| Folder | Paper section | What it computes |
|---|---|---|
| `image_deviation/` | §4, App. F.1 | Pixel, structural, perceptual, and embedding distances between paired images; within- vs. across-scene CLIP cosine |
| `text_deviation/` | §4, App. F.2 | Token-level and sentence-embedding distances between paired captions |
| `object_count/` | §4, App. F.3 | OWLv2 object counts per image (CompoSET vs. Winoground, BiVLC, SugarCrepe) |
| `cosine_margin/` | App. G.3 | Per-pair cosine margins, correct vs. wrong decisions |
| `scene_edit_hard/` | §5, App. C, App. G.3 | Scene-clustered bootstrap CIs; scene-hard vs. edit-hard checks |
| `composet_eval/` | (shared) | Loaders for prior benchmarks, used by the deviation scripts |

## Setup

Run from the repository root, with the package dependencies from `pyproject.toml` installed. Some scripts also need
`lpips`, `DISTS-pytorch`, `pytorch-msssim`, `scikit-image`, `open_clip_torch`, `sentence-transformers`, and `editdistance`.

Paths are relative to the repository. Three environment variables override the defaults:

- `COMPOSET_DATA_DIR`: a local copy of the dataset. If unset, the scripts download `CompoSET/CompoSET` from Hugging Face.
- `COMPOSET_RESULTS_DIR`: per-model result CSVs written by `python -m eval.run`. Default: `results/`.
- `COMPOSET_BENCHMARKS_CACHE`: cache for prior-benchmark images. Default: `paper/analysis/.benchmarks_cache/`.

`cosine_margin/` and `scene_edit_hard/` need model results first, for example
`python -m eval.run --output results/` and `python -m eval.run_all_benchmarks`.
